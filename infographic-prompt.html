Generate On-Brand Infographics for Any Article Using AI

⏱ 5 min read 7 steps By Mustansar Mahmood
A copy-paste master prompt that turns any article into section-by-section infographic prompts — one per H2. Feed it your brand colors, paste your article, and you get ready-to-render prompts for Gemini. No design skills needed.

Tools You'll Need

This workflow uses two AI tools in sequence — Grok to generate the prompts, Gemini to render the actual images.

🤖
Grok (by xAI) Prompt generation
✨
Gemini Pro / Nano Image rendering
🎨
Color Picker (browser ext) Get your brand hex codes

The Master Prompt

Copy this exactly. Do not modify it. The placeholders at the bottom are where you add your content and brand details each time you use it.

📋 Master Prompt — copy exactly
You are an expert infographic prompt generator. Your task is to create separate, ready-to-use image generation prompts for each H2 heading in the provided article content.

Strict rules you must follow:
Only generate prompts if the user provides BOTH the full article content AND the brand branding details (colors, and any font preferences if mentioned). If either is missing, respond only with: "Please provide the full article content and brand colors to proceed."
Generate ONE separate prompt per H2 section in the article. Number them clearly (e.g., Prompt 1 for [H2 title], Prompt 2 for [H2 title], etc.).
Each individual prompt must be in 16:9 aspect ratio.
Each infographic must be bold, modern, visually appealing, high-contrast, and professional.
Prioritize visual graphics over text — the goal is for anyone to understand the key message in 3 seconds just by looking.
Always include the exact H2 title as a prominent large heading at the top.
Use minimal text in the body — summarize the section very concisely using only the most essential points, short phrases, or bullet-style labels.
Use large, clear icons or shapes only when they directly represent the core concepts described in the section (e.g., accurate oven symbols, steps in a process, timelines). NEVER add extra illustrative icons (especially food, people, or unrelated objects) unless explicitly described in the content as the main subject.
Incorporate the provided brand colors exactly: [list them here when you use the prompt, e.g., main #DD2525, secondary #191E25, tertiary #F4F5F6].
Always end each prompt with: "Place the logo in the center bottom."
Do not add any extra instructions or commentary outside the numbered prompts.

## Now, here is the article content and branding:

[PASTE FULL ARTICLE CONTENT HERE]

Brand colors: [PASTE BRAND COLORS HERE, e.g., Main color: #DD2525, Secondary color: #191E25, Tertiary color: #F4F5F6]
[Any font preferences if you have them]

Generate the infographic prompts now.
💡 Pro tip: Use the Color Picker and Font Picker browser extensions on your client's website to pull exact hex codes and font names before you run this prompt.

How to Use It — Step by Step

Seven steps from blank page to finished infographic.

  • 1
    Copy the master prompt Hit the Copy button above and paste it into a new Grok conversation.
  • 2
    Add a separator Type five dashes (-----) below the prompt to signal the end of instructions.
  • 3
    Enter your branding Add brand colors (hex codes) and font preferences. Use Color Picker and Font Picker extensions to grab them from the client's site. Add another ----- after.
  • 4
    Paste your article and press Enter Drop the full article content below the last separator and run it.
  • 5
    Grok generates one prompt per H2 You'll get numbered, ready-to-render prompts — one for every H2 section in your article.
  • 6
    Take each prompt to Gemini Open Gemini Pro or Nano. Paste one prompt at a time and press Enter.
  • 7
    Screenshot the brand logo and attach it Paste a screenshot of the client's logo into the Gemini chat along with each prompt. The prompt already instructs Gemini to place it at center bottom. Done — you have your infographic.
